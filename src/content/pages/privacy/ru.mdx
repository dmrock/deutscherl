## Статистика посещений

Мы считаем просмотры страниц с помощью Cloudflare Web Analytics. Этот сервис не использует cookie и хранилище браузера и не составляет твой профиль. Мы видим только общие числа: например, сколько раз открывали страницу, из какой страны и в каком браузере.

## Хранилище в твоём браузере

Сайт сохраняет в браузере две небольшие вещи. Они не покидают твоё устройство, и мы их не видим:

- **Тема**: если ты переключаешь светлую и тёмную тему, выбор сохраняется (local storage, ключ `theme`), пока ты его не удалишь.
- **Упражнения**: задания темы, которые ты уже видел (session storage, ключи `seen:…`), чтобы в следующем раунде были другие задания. Эти данные удаляются, когда ты закрываешь вкладку.

И то и другое можно в любой момент удалить в настройках браузера.

## Поиск

Поиск работает полностью в браузере: он загружает поисковый индекс с этого сайта, а твои запросы никуда не отправляются.

## Ссылки на GitHub

«Сообщить об ошибке» и другие ссылки на GitHub ведут на сайт GitHub (GitHub, Inc.). Там действует политика конфиденциальности GitHub. Мы видим только то, что ты пишешь в issue.
